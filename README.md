\## 📖 项目简介



这是一款 \*\*2D俯视角像素风\*\* 的生存探险动作角色扮演游戏（ARPG）。

游戏视觉氛围参考《饥荒》，但数值体系与战斗玩法效仿《泰拉瑞亚》。游戏主打 \*\*低生存压力、高探索与战斗自由\*\*。



玩家将出生在温和的起始区，通过砍树、挖矿、击败怪物来收集资源，合成带有随机词条的装备，逐步探索地下矿洞、沙漠、冰雪地带、天空岛以及诡异之地。游戏没有强制的固定结局，玩家的核心驱动是击败区域Boss、收集远古神器，在沙盒世界中无限变强。



\## ✨ 核心特性



\- \*\*🔴 双资源系统\*\*：玩家拥有生命值（红心）和魔力值（蓝量）。魔力值用于释放魔法、召唤物或辅助技能，可自动缓慢回复，也可通过药水快速回复。

\- \*\*⚔️ 混合职业战斗\*\*：玩家可自由搭配近战（不耗蓝）、远程（消耗弹药）、魔法（消耗魔力）和召唤流，战斗风格灵活多变。

\- \*\*🌍 多元生态群落\*\*：包含温和起始区、地下矿洞、沙漠、冰雪地带、天空浮空岛和诡异之地。每个地形拥有独特的环境、怪物和产出。

\- \*\*🎒 随机词条装备\*\*：装备分为白、绿、蓝、紫等品质，并附带随机词条（如“+10%暴击率”、“+5点魔力”）。BOSS和精英怪掉落随机属性装备，提供极高的刷装备乐趣。

\- \*\*🏗️ 丝滑开局体验\*\*：向导NPC指引 + 快速撸树 + 开局赠送基础武器。摒弃繁琐的前期生存压力，让玩家快速投入战斗。

\- \*\*👑 挑战区域Boss\*\*：前期规划2-3个Boss，分布在特定地形。击败Boss获取核心材料和神器碎片，驱动游戏进程。



\## 🛠️ 技术栈



\- \*\*游戏引擎\*\*：Unity 2021.3.20f1c1 LTS

\- \*\*渲染管线\*\*：Universal 2D (URP) - 用于实现2D动态光照、昼夜交替和粒子效果

\- \*\*开发语言\*\*：C#

\- \*\*核心包\*\*：2D Tilemap Editor（地图搭建）、Cinemachine（相机跟随）、A\* Pathfinding（可选，怪物AI寻路）



\## 🎮 游戏设计文档 (GDD)



\### 1. 游戏循环 (Gameplay Loop)

`探索新区域` → `遭遇怪物/采集资源` → `获取战利品（材料、金币、装备）` → `合成/购买更强装备` → `挑战Boss` → `解锁新区域或神器` → `继续探索`



\### 2. 地图与生态 (World \& Biomes)

| 生态区域 | 视觉风格 | 怪物类型 | 核心产出 |

| :--- | :--- | :--- | :--- |

| \*\*温和起始区\*\* | 森林/平原 | 史莱姆、小蝙蝠 | 基础木材、矿石、新手装备 |

| \*\*地下矿洞\*\* | 昏暗曲折 | 骷髅、洞穴蜘蛛 | 高级矿物、地下宝箱 |

| \*\*沙漠/干旱地带\*\* | 黄沙漫天 | 木乃伊、蝎子 | 特殊植物、玻璃、沙漠专属装备 |

| \*\*冰雪/冻土\*\* | 严寒地带 | 冰史莱姆、雪怪 | 冰雪武器、特殊饰品 |

| \*\*天空/浮空岛\*\* | 云端高悬 | 特殊飞行怪 | 稀有战利品、后期道具 |

| \*\*诡异之地\*\* | 压抑敌意 | 主动攻击型怪物 | 暗影装备、召唤Boss材料 |



\### 3. 开局体验设计 (Onboarding)

1\. \*\*出生\*\*：降生在温和起始区，身边有一名向导NPC。

2\. \*\*指引\*\*：向导提示玩家“砍树收集木材，制作基础装备”。

3\. \*\*撸树\*\*：砍树过程极简（一两下即倒），快速获取木材。

4\. \*\*武装\*\*：使用木材合成工作台和木剑/木弓，或获得向导赠予的生锈铁剑。

5\. \*\*首战\*\*：向导指引去附近击败史莱姆，获取金币和凝胶，正式开启探险。



\### 4. Boss 设计规划（前期2-3个）

\- \*\*Boss 1：巨型史莱姆王\*\*（新手入门）

&#x20; - \*\*位置\*\*：温和起始区 / 地下矿洞入口

&#x20; - \*\*机制\*\*：跳跃攻击、召唤小史莱姆、分裂

&#x20; - \*\*掉落\*\*：前期强力武器、大量金币、解锁新区域的钥匙

\- \*\*Boss 2：诡异之眼（克苏鲁之眼）\*\*

&#x20; - \*\*位置\*\*：诡异之地

&#x20; - \*\*机制\*\*：飞行冲撞、召唤眼球仆从、发射暗影射线

&#x20; - \*\*掉落\*\*：暗影矿石、诡异锭（用于合成高级魔法装备）

\- \*\*Boss 3：沙漠法老 / 地下蠕虫\*\*

&#x20; - \*\*位置\*\*：沙漠深处 / 地下深层

&#x20; - \*\*机制\*\*：召唤沙尘暴、钻地突袭、诅咒

&#x20; - \*\*掉落\*\*：抓钩、二段跳饰品或专属法杖



\### 5. 物品与经济系统

\- \*\*资源收集\*\*：木材、矿石、皮革、宝石、怪物掉落物。

\- \*\*合成系统\*\*：基础但丰富的合成表，需要工作台、熔炉、铁砧。

\- \*\*装备品质\*\*：白、绿、蓝、紫等品质，附带随机词条，玩家需反复刷怪/刷Boss获取完美属性。
